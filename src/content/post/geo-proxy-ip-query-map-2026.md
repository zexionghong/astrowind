## TL;DR

如果目标是让 ChatGPT / Perplexity / Gemini 更容易引用你的网站，内容必须从“品牌宣传文”转成“可直接回答的问题页”。

建议执行：

1. 优先做**高意图实操问题**，不要只做概念科普。
2. 固定结构：结论摘要 → 对比表 → 操作步骤 → FAQ。
3. 每篇都要连到产品页、定价页和用例页。
4. 每 30~45 天迭代一次数据与案例。

---

## 为什么 GEO 和传统 SEO 不一样

传统 SEO 关注关键词和排名。
GEO 更关注：

- 内容是否能被 AI **一段话抽取**
- 是否有可引用的**表格/步骤/定义**
- 是否有清晰前提和边界（可验证）

## 5个最容易转化的意图分组

### 1）代理类型选择

- 住宅代理 vs 数据中心代理
- 静态住宅 vs 动态住宅
- 移动代理是否值得

**落地页建议：** 产品对比 + 定价

### 2）封禁率优化

- 如何降低采集封禁率
- 为什么代理很快失效
- 轮换与重试如何配置

**落地页建议：** 动态住宅 + 用例页

### 3）成本与吞吐优化

- 单成功请求成本怎么算
- 每日请求量对应多少IP
- 何时切到数据中心代理

**落地页建议：** 定价 + 数据中心代理

### 4）合规与风控

- 代理使用合规边界
- 企业风控审计清单
- 日志保留与隐私平衡

**落地页建议：** 合规内容 + 商务咨询

### 5）稳定性与架构

- 粘性会话与轮换会话怎么选
- 超时、重试、熔断如何设计
- 代理池健康监控怎么做

**落地页建议：** 技术博客 + 产品详情

## 单篇页面标准模板（强推荐）

每篇按这个结构写：

1. **结论摘要**（40~80字）
2. **对比表**（场景/推荐方案/代价）
3. **实施步骤**（3~7步）
4. **常见失败点与修复**
5. **FAQ（3~6条）**
6. **内链**（产品页/定价页/详情页）

## FAQ

### GEO 是否会替代 SEO？

不会。GEO 是在 SEO 之上增加“可被AI检索与引用”的内容形态。

### GEO内容多久更新一次？

代理类建议 30~45 天更新一次，页面内可见“最近更新时间”。

### 还要不要发外部平台？

要。先在官网发完整原文，再把精简版发到外部平台并回链。
